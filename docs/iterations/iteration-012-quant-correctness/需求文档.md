# 迭代 012：量化正确性

## 背景

审计量化维度确认：comparison-profile-v1 政策文件的 metric_overrides 是死
配置（代码硬编码容差，与政策漂移）；precomputed_ml 在未声明自定义 line 时
静默降级为 SMA 基线策略；extra_metrics 扩展点不可达（worker 只装 4 个固定
analyzer）；运行时指纹只哈希 version.py（脏 checkout 不可见、pandas/numpy
不入环境指纹）；注册无 OHLC 价格合理性校验；无 seed 机制（随机策略不可
复现）。

## 目标

1. **比较政策单一来源**：compare_metrics 从打包政策加载默认容差与
   metric_overrides（final_value 收紧至 rel 1e-9/abs 1e-6），测试锁定
   政策↔实现一致。
2. **precomputed_ml fail-fast**：StrategySpec.parse 要求 precomputed_ml 声明
   至少一条自定义 line，否则 InvalidRequest（不再静默降级）。
3. **analyzer 白名单**：StrategySpec.extensions.analyzers 允许
   `["sqn","calmar","vwr","timereturn"]`；worker 经环境传递，候选进程
   addanalyzer 并汇入 extra_metrics。
4. **运行时指纹升级**：run-manifest 的 engine 记录 git HEAD commit，环境指纹
   纳入 pandas/numpy 版本；prepare/start 双闸门复核 commit。
5. **OHLC 数据质量门禁**：注册期拒绝非正价格与 bar 内不一致
   （high<low、high<max(o,c)、low>min(o,c)），错误含行号。
6. **seed 机制**：StrategySpec 可选 `seed`（0..2^32-1）；冻结进 run-manifest
   并经环境传入候选进程，入口处设置 random/numpy 种子。

## 非目标

- derive→precomputed_ml 管道修复（warmup 策略与 input_format 声明）、
  alignment 收紧、参数扫描、模板升级、walk-forward、bar_operation 全参数
  暴露（013 产品能力）。
- MT5 秒级截断防护与时区语义（013 数据质量扩展）。

## 验收标准

R1-R6 对应上述目标；R7 全量回归 ≥80% 覆盖率 + ruff/mypy/协议测试 + 清洁
wheel 14 格矩阵通过。

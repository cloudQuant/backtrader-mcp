## 2. 失败处置

- A1：不要弱化 audit assertion；修正 finding 的实现或测试期望。
- A2：禁止将 CLI 改为直接抛无结构化异常；保持 ProductError 的 JSON 行为。
- A3：禁止将非有限数或 bool 视为普通数字以换取 green。
- A4/A5：不降低阈值/加 omit；补精准的边界测试。
- A6/A7：冻结下一轮，先恢复公开 runtime 和 isolated distribution 证据。

# 迭代 010：授权可信分离与安全加固设计

## 架构决策

1. **nonce 台账放 SQLite**（新表 `nonces(nonce TEXT PRIMARY KEY, used_at TEXT)`）：
   `issue()` 登记 nonce（碰撞则重生成，最多 3 次）；`verify()` 在
   `BEGIN IMMEDIATE` 内原子消费（未见/已用 → Forbidden）。`TokenSigner`
   签名改为 `TokenSigner(state_root, state: StateStore | None = None)`；
   state 为 None 时跳过台账（独立 CLI/测试路径）。
2. **审批身份进审计**：`approve_change`/`approve_run_plan` 的成功路径在
   audit 详情中加入 `approver`（uid/username；`getpass.getuser()` +
   `os.getuid()`，非 POSIX 降级 username-only）。
3. **结果契约 identifier 白名单**：worker 侧正则
   `^[A-Za-z_][A-Za-z0-9_.]{0,127}$`；Markdown 渲染前对 extra metric 名
   做字符白名单过滤（`[A-Za-z0-9_.-]`，否则用 `repr` 转义输出）。
4. **锁平台分支**：`locks.py` 顶层改为 try/except ImportError；POSIX 用
   fcntl，Windows 用 msvcrt.locking（对文件头 1 字节加锁）。
5. **rlimit 状态**：`_apply_resource_limits` 返回 `[{resource, applied}]`；
   worker 写 `resource_limits_status` 进 job 行并 audit。

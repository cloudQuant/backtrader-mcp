# 迭代 005：验收文档

## 1. 验收用例

| ID | 场景 | 命令/操作 | 通过标准 |
| --- | --- | --- |
| A1 | 版本 red/green contract | pytest --no-cov tests/test_release_version.py tests/test_cli_doctor.py | 开发前红、修复后 package/doctor/service/server 源绑定一致。 |
| A2 | wheel metadata | BACKTRADER_MCP_WHEEL=... pytest --no-cov tests/test_wheel_distribution.py | METADATA 与安装后 package 均为 0.2.0。 |
| A3 | 文档 | 审阅 README/CHANGELOG/pyproject | 无错误 0.1.x/0.1.0 release 声明；dynamic version path 正确。 |
| A4 | 静态质量 | Ruff、mypy、independence audit、git diff --check | 零格式、类型、独立性或补丁错误。 |
| A5 | 全量 | PYTHONPATH=src pytest -q | coverage ≥80%，所有原有和新增测试通过。 |
| A6 | 公开 runtime | PyPI backtrader==1.9.78.123 全量 pytest | 全部通过且 coverage ≥80%。 |
| A7 | clean-room | scripts/run_acceptance.py --matrix all --require-no-skills --require-no-agent | wheel SHA、14/14、wheel/协议/独立性均通过。 |

## 2. 失败处置

- A1 失败：禁止只改测试期望；消除 runtime 的硬编码版本或修复 dynamic metadata 路径。
- A2 失败：禁止把 wheel metadata 检查移除；先修复 build config。
- A3 失败：只修正事实性 release wording，不重写兼容性/迁移政策。
- A5-A7 失败：停止完成声明，恢复可复现构建和环境一致性证据。

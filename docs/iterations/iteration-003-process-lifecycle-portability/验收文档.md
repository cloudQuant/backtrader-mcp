## 2. 失败处置

- A1/A2 失败：停止合并，修复 helper 平台分支；禁止在 Windows 分支重新传入 POSIX-only
  Popen kwargs。
- A3 失败：只补运行所需的精确变量，禁止退回完整 `os.environ` 继承。
- A4/A5/A6 失败：先保留 job 状态/审计语义，再修复终止调用；不以吞掉异常掩盖残留进程。
- A7/A8 失败：冻结下一轮，先恢复公开 runtime 和 isolated wheel 证据。

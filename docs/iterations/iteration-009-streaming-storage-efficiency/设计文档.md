# 迭代 009：流式数据管道与存储效率设计

## 架构决策

1. **"有界单读 + 流式写出"替代全量物化**。源文件受 `max_dataset_bytes`（默认
   64 MiB）硬上限，读入一次 raw bytes（有界）；解析用
   `TextIOWrapper(BytesIO(raw), encoding="utf-8-sig")` + `csv.DictReader` 惰性
   行迭代（每行 dict 用完即弃）；规范化行直接写临时文件并同步增量更新规范
   内容哈希；读后对源文件再做一次哈希以保证"读取期间未变化"语义不变
   （共 2 次磁盘读，旧实现为 3 次 + 3 份内存副本）。临时文件校验通过后原子
   改名进 CAS（沿用 atomic_write 语义）。
2. **源级去重是 manifest 查找**。register 先算源 sha256，再
   `state.list("dataset")` 中找 `provenance.source_sha256 == source_hash` 且
   `column_map`/`extra_columns`/`adapter_options` 相同（canonical JSON 比较）
   的既有 manifest，命中则直接复用其 `extensions.feed_objects` 并跳过解析。
   物理 CAS 层保留既有按内容哈希的落盘去重。
3. **对齐检查只物化 master**。master 时间戳集合 + 其余 feed 逐行
   `in master_set` 计数求交；overlap 语义与旧 `set.intersection` 完全一致
   （unique 计数），仅内存形态改变。
4. **refresh 以文件指纹缓存 + 整表替换**。新增 objects kind
   `catalog_file_cache`（id=relative_path，payload={sha256, mtime, size}）；
   指纹未变则跳过读文件与 AST 解析并复用缓存哈希；新增
   `StateStore.replace_kind(kind, rows)`（单事务 DELETE kind 全部行 +
   批量 INSERT）替换逐条 put，同时天然清除陈旧条目。dual corpus 与 AST 路径
   共用同一机制。
5. **SQLite 连接按线程缓存**。`StateStore.connect()` 用 `threading.local`
   每线程持一个连接（服务端 watchdog 与主线程各自独立），进程生命周期不关闭，
   消除 2218 个 ResourceWarning；`BEGIN IMMEDIATE`/`busy_timeout` 语义不变。
6. **GC 以引用扫描为准**。CAS 回收先收集全部 dataset manifest 引用的
   `cas_relative_path`（含派生数据集），再删除未被引用、文件名匹配
   `[0-9a-f]{64}` 且 mtime < before 的文件；drafts 排除被 run_plan/job 引用的
   draft_id；approvals 删 `used_at < before` 或 `expires_at < before` 的行。
   所有 clean 走审计 + WAL checkpoint。
7. **耗时打点用 contextmanager**。`logging_config.timed(logger, event, **fields)`
   输出 `event duration_ms=...`；挂到注册/派生/refresh/search/preview。
   `util.FileHashCache`（(inode,mtime,size) 键、限量 LRU）仅供
   preview/inspect 使用。

## 接口契约

- `DatasetService._read_and_hash(path) -> (bytes, str)`：单次读 + sha256。
- `DatasetService._stream_canonical(raw, column_map, extra_columns,
  adapter_options) -> (bytes, int)`：流式规范化，返回规范内容与行数（内容
  在临时文件累积后读出；≤64 MiB 上界）。
- `DatasetService._find_registered(source_hash, column_map, extra_columns,
  adapter_options) -> dict | None`。
- `StateStore.replace_kind(kind, rows: list[dict]) -> int`：单事务整表替换，
  返回写入行数。
- `StateStore.clean_approvals(before_iso) -> int`。
- `JobService.clean_cas(before_iso) -> dict`；`JobService.clean_drafts(
  before_iso) -> dict`。
- `logging_config.timed(logger, event, **fields)`：contextmanager。
- `util.FileHashCache(max_entries=256).hash(path) -> str | None`（未缓存时
  None，由调用方回退 file_hash 并 put）。
